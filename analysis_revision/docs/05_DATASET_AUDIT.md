## 2. 硬阻断

### 2.1 GSE255786 缺少 PJI 标签 → 原"最快路径"不可执行

93 个样本的全部 characteristics 键只有 `tissue: Knee/Hip` 与 `cell type: Sonicate fluid`。
SRA runinfo(PRJNA1076519)的 `Disease` 列全空;GEO 无 PubMed 链接、无 series 级标签文件、BioSample 无附加属性。

没有分组变量就没有 ROC / AUC / EMI 判别曲线。

**次生风险**: 该数据集的原始论文本身已完成 PJI vs 非感染失败的差异表达,确认 28 个已报道标志物并新报 3 个。
复现该判别不构成新结果。

**解除条件**: 从论文补充材料取回每例感染状态,并映射到计数矩阵列名所用的内部编号(1005 / 1006 / 1013 …)。

### 2.2 全队列零临床混杂变量 → Direction 3 不可识别

| 数据集 | 全部可用 characteristics 键 |
|---|---|
| GSE165816 | `tissue`, `disease`(含 DFU-healer / DFU-nonhealer) |
| GSE231643 | `tissue`, `cell type`, `race` |
| GSE80178 | `tissue`, `disease state` |
| GSE255786 | `tissue`, `cell type` |

`directions/03/SPEC.md` 要求 $X$ = 年龄、性别、病程、HbA1c、BMI。**这些字段在任何一个数据集中都不存在。**
没有 $X$,Neyman 正交化与交叉拟合失去对象,DML 退化为二元关联检验。

当前代码状态:`run_direction3_pipeline.py` 仅 `print` 出混杂变量名称而不加载任何数据;
`mock_verification.py` 用 `np.random.normal(62, 10)` / `np.random.normal(8.2, 1.5)` 自行编造年龄与 HbA1c。
preflight 的 PASSED 是模拟器自我对账,**不构成证据**。

### 2.3 RAAG 拓扑审计在目标规模上 OOM(已修复)

原实现在 `cdist`、`same_ref/same_cand` 外积、`shortest_path` 三处均为稠密 O(N²)。

实测原实现标度(拟合 ~N^2.2):

| N | 耗时 | 峰值 RSS |

| 3,000 | 1.28 s | 0.18 GB |

## 4. 新发现:跨样本基因索引不一致

54 个 CSV 的基因列表并不相同:

- 单样本基因数 **14,364 – 21,134**(中位 18,227)
- 并集 **26,923**
- 严格交集仅 **10,645**

由于 CSV 是稠密格式却各自基因数不同,说明投稿方已按"该样本中检出"过滤,

严格交集会剔除掉正是本课题关注的样本特异性炎症标志物:**MMP1 / MMP3 / MMP13 / IFNG 全部丢失**。
改用并集后 23/23 靶标调控子全部保留。

`core_engines/data_adapter.py` 的 `gene_policy` 默认为 `"union"`,并保留 `"intersection"` 选项。

## 6. GSE231643 方向性冻结投影（标题标签，不是患者级独立验证）

`scripts/11_validate_gse231643.py`。**模型与基因面板全部冻结**:编码器权重、主题-基因矩阵 beta、
7,002 基因靶线均取自 GSE165816 检查点,GSE231643 只做投影,不重新训练。

标签从样本标题还原(GEO 未将愈合状态暴露为 characteristics 键):**H1–H5 = healer(5 例),NH1/NH2/NH4 = non-healer(3 例)**。

这些标签只能支持方向性构念比较，不能通过 `prognostic` 患者合同：GEO 没有权威患者 ID、随访窗口或样本到文库的完整追踪。因此本节的“验证集”数字不进入实验 A，也不能被写成患者级独立验证。

- 载入 35,655 细胞 / 36,591 基因(8 例,10x CellRanger 7.0.0),QC 后 **30,484 细胞**
- 靶线覆盖率 **6,752 / 7,002 = 96.4%**,250 个基因零填充

### 6.1 发现集结论的复现情况

数字取自第 7.5 节修复后的确定性投影。

| | 发现集 GSE165816 | GSE231643（标题标签投影） |
|---|---|---|
| topic 0 (TIMP1/CHI3L1/COL3A1/FN1) healer | 0.0723 | 0.1801 |
| topic 0 non-healer | 0.0265 | 0.0702 |
| **比值** | **2.72x** | **2.56x** |
| 样本级 p | 0.0599 | **0.1429(不显著)** |

**方向与效应量在标题标签投影中一致,统计显著性未达成。** 逐样本看,H1 的 topic 0 载荷落进了非愈合组区间,
这一个交叉点就足以让 n=5 vs 3 的秩检验失去显著性。

注意本节比较的是**全样本平均 θ**,它把「程序强弱」和「细胞组成」混在一起。
第 7 节的细胞类型内重测表明,GSE231643 投影的 2.56x 里约六成来自组成差异而非程序差异。

### 6.2 功效上限:这个样本量下没有任何结论能通过多重检验校正

n=5 vs 3 时 Mann-Whitney 两侧 p 的**理论下限是 0.0357**(完全分离时取得)。
15 个主题做检验,Bonferroni 阈值为 0.05/15 = **0.0033**,低于该下限。
因此 **本标题标签投影在结构上不可能产出经多重校正后显著的结果**,这是样本量决定的,不是分析方法的问题。

15 个主题中只有 **topic 5(KRT14/KRT10/KRT5/KRT1,角质细胞)**达到下限:
healer 0.0120 vs non-healer 0.0339(**0.36x**,非愈合组更高),8 例完全分离,p = 0.0357。
该结果应视为假设而非结论,且存在取材方式混杂 —— GSE231643 是**清创组织**,GSE165816 是**手术切取标本**,
两者的上皮成分占比本就不可比。

### 6.3 关于细胞级 p 值

脚本同时输出了细胞级检验 p = 1.04e-196。**该数字不得作为结果报告**:
同一患者的细胞不是独立重复,30,484 个细胞背后只有 8 个受试者,细胞级检验是伪重复(pseudoreplication)。
脚本中已将其显式标注为 `PSEUDOREPLICATED`。

**结论**: 发现集的 HE-Fibro 信号在 GSE231643 的标题标签投影中方向一致、效应量接近(2.8x → 2.5x),
但该队列没有通过权威患者合同，也不具备独立的患者级确认资格。若要主张该结论,需要新的独立 DFU 队列。

## 7. 细胞类型内重测:把「程序强弱」和「组成差异」劈开

`scripts/12_celltype_resolved_test.py`。全样本平均 θ 无法区分两种互斥解释:
**(A)** 愈合组成纤维细胞内部的 TIMP1/CHI3L1 程序更强(生物学主张);
**(B)** 愈合组样本里成纤维细胞占比更高(取材假象)。后者是主要竞争解释,因为
GSE231643 是清创组织、GSE165816 是手术切取标本。

**循环论证守卫**:谱系判定用经典标志物,成纤维面板刻意排除了 topic 0 的 top 基因
(DCN/LUM/COL3A1 虽是真成纤维基因但在 topic 0 前十,改用 COL1A1/COL1A2/PDGFRA/TWIST2 承担身份判定)。
脚本对 `topic0 ∩ fibroblast_panel = ∅` 做**断言**而非描述,不满足则直接退出。

### 7.1 结果

| | 发现集 GSE165816 | GSE231643（标题标签投影） |
|---|---|---|
| 成纤维占比 healer vs nonhealer | 0.298 vs 0.209 = **1.42x, p=0.4376** | 0.354 vs 0.173 = **2.05x, p=0.0714** |
| 全样本 topic 0 | 2.72x, p=0.0599 | 2.56x, p=0.1429 |
| **成纤维细胞内 topic 0** | **2.89x [1.06, 13.97], p=0.0420** | **1.66x [1.01, 6.10], p=0.1429** |
| 样本数 | n=9 vs 5(p 下限 0.0010) | n=5 vs 3(p 下限 0.0357) |
| 留一法比值区间 | 2.40x – 7.87x(稳健) | 1.21x – 2.44x(脆弱) |

**两个队列给出不同答案:**

- **发现集支持 (A)**。组成差异不显著(1.42x, p=0.44),而成纤维内部效应不降反升(2.72x → 2.89x),
  留一法下最低仍有 2.40x。这是「程序强弱」而非「细胞数量」。
- **GSE231643 投影大部分是 (B)**。成纤维占比本身差了 2.05x,而效应从 2.56x 衰减到 1.66x,
  置信区间下界压在 1.01,去掉 NH4 一例即跌到 1.21x。**约六成的表观效应来自组成。**

### 7.2 组成本身印证了取材混杂

| 谱系 | GSE165816(手术切取) | GSE231643(清创) |
|---|---|---|
| 角质细胞 | 14.2% | ~2.2% |
| 髓系 | 7.4% | **21.0%** |

清创组织富含髓系、几乎没有上皮,与预期完全一致。这既验证了标志物打分本身可靠,
也解释了上一节 topic 5(角质细胞)为何出现「8 例完全分离」—— 那是取材方式差异,不是生物学。

### 7.3 发现集的 p=0.0420 仍然是乐观的

足皮肤 DFU 臂用到 **14 个 GSM**,但原文声明只有 **11 例 DFU 患者**,即至少 3 个是同一患者的重复取样。
样本标题是 G1/G1A/G2/G2A… 的**样本编号而非受试者编号**(G1 是「非糖尿病前臂」、G1A 是「糖尿病无 DFU 足部」,
证明二者不是同一人),**GEO 没有任何字段能把重复样本合并**。脚本已将此作为运行时 WARNING 输出并写入 report.json。

因此 p=0.0420 假定了 14 个独立样本,而真实独立单元 ≤11。该数字**不能按面值报告**。

### 7.4 双峰已解释:是成纤维两种状态的混合比例,愈合专属性尚未验证

`scripts/13_bimodal_stratification.py`。零新增下载,复用第 7 节 parquet,3 秒跑完。
预指定两条互斥读法:

- **SHIFT**:高均样本里每个成纤维细胞都把程序开大了(高组 p10 > 低组 p90,两分布几乎不重叠)
- **MIXTURE**:高均样本只是高-θ 状态细胞更多,其余细胞仍停在低状态(高组仍与低组重叠)

| 判定 | 发现集结果 |
|---|---|
| 愈合臂模式 | 高 4 / 中 1 / 低 4 |
| 高组成纤维 p10 中位数 | **0.029** |
| 低组成纤维 p50 / p90 | 0.025 / 0.119 |
| SHIFT | **否**(0.029 ≪ 0.119) |
| MIXTURE | **是** |
| 样本均值 vs 混合权重 | Spearman ρ = **0.933** |
| healer 是否预测高模式 | Fisher p = **0.221**(4/9 vs 0/5) |

高均愈合样本(G4/G7/G15/G23)的 p10 仍是 0.014–0.046,与低均样本同一量级,p90 却到 0.68–0.82。
样本均值几乎就是「高-θ 成纤维占比」(GMM 分界 0.184;高组混合权重 0.59–0.70,低组 0.02–0.14)。
第 7.1 节的 2.89x **不是**成纤维整体程序强弱,是 HE-Fibro 样细胞在成纤维里的混合比例。

**该状态不是愈合特异的。** 切点在愈合臂上定好后原样套到其他臂:

- G16(`GSM5050540`)健康非糖尿病足皮肤:均值 0.466,混合权重 0.841,形状是 **pure_high**(p10=0.128)——几乎整群都在高状态,比任何愈合样本都纯
- G6(`GSM5050530`)非愈合:均值 0.250(记为 mid),形状与愈合高组一样是 **mixed**(p10=0.021, p90=0.649)

愈合标签对高模式没有显著预测力。成纤维细胞数无关(ρ=−0.018);G 编号(GEO 样本序)无关(ρ=−0.34, p=0.10)。
弱相关只剩全样本髓系占比(ρ=0.40, p=0.047)以及成纤维内部的 topic 4(ACTA2/TAGLN)与 topic 11(HLA-DR),ρ≈0.61——高-θ 状态更像活化/炎症成纤维,不是静息基质(topic 2 不跟)。

GSE231643 投影没有低模式愈合样本,SHIFT/MIXTURE 判定不适用;H2–H5 偏 pure_high,H1 和 NH4 拉低均值。两套取材下「高-θ 成纤维」的基线本身就不同,不能把发现集的混合权重直接当患者级验证终点。

**主张必须改写**:可辩护的是「部分样本的成纤维里有一群 TIMP1/CHI3L1 高状态,其丰度在愈合臂里双峰、在健康皮肤里也能走到纯群」。不能再写成已验证的愈合标志。

### 7.4b 伪迹排查:高-θ 状态不是解离应激、不是双联体、不是测序深度

`scripts/14_artifact_triage.py`。7.4 把双峰定性为混合比例后,在写成生物学之前必须先排除技术解释。
两条已有证据使这一步是强制的:topic 0 的 top10 含 **IER3 与 SOD2**(应激基因,IER3 属标准解离伪迹基因集),
且高状态与 topic 11(HLA-DR/CD74)ρ≈0.61、与全样本髓系占比 ρ=0.40 —— 后者正是成纤维-髓系双联体会产生的模式。

四条假设的判据在运行前固定,判定由规则算出而非事后叙述:

| 假设 | 判据 | 实测 | 结论 |
|---|---|---|---|
| **H1 解离应激** | 细胞级 SMD>0.8 **且** 样本级 ρ>0.6 | SMD=**+0.25**,ρ=+0.14 (p=0.489) | 不成立 |
| **H2 双联体/谱系混入** | PTPRC+ 比率之比 >2.0 | 0.984% vs 0.616% = **1.60x**;髓系 SMD=+0.66;角质 SMD=−0.01 | 不成立 |
| **H3 测序深度** | log10UMI 或 nGenes SMD >0.8 | log10UMI SMD=**+0.70**(中位 12,190 vs 7,089),nGenes=+0.59 | 不成立(**最接近阈值**) |
| **H3b 深度对照** | 降采样后样本混合权重 ρ>0.8 | 14,551 细胞降至**精确 986 面板 UMI**;细胞标签一致率 **99.5%**,ρ=**+0.984** | **存活** |

H3 贴着阈值(原始中位 UMI 差 1.7 倍),所以不争论阈值而是直接消除深度:
对每个成纤维做多元超几何降采样至同一面板计数,再用同一冻结模型重投影。状态判定几乎不变。

⚠️ 首次实现的深度对照是**静默无操作**:`target` 取自全转录组 UMI(4,805),却拿去与 **7,002 基因面板内**
的计数总和比较,面板计数几乎总是更小,分支从不触发,却报出「一致率 100%、ρ=1.000」的假通过。
已改为在面板空间取阈值,并断言 `n_changed > 0` 与 `max(panel_umi) == target`。

**结论**:高-θ 成纤维状态是真实的细胞状态,不是组织处理或测序深度的产物。
残留关注点是髓系评分 SMD=+0.66(PTPRC+ 两组均 <1%,粗双联体已排除,但环境 RNA 未排除)。

### 7.4c 分层因素找到了:它是组织免疫浸润轴,不是愈合能力

`scripts/15_stratifier_sweep.py`。7.4 称分层因素「未识别」,该说法只有在系统搜索过之后才成立。
对 25 个样本、31 个协变量做 Spearman 扫描并作 BH 多重校正。**14 个通过 q<0.05**:

| 协变量 | ρ | q_BH |
|---|---|---|
| B/浆细胞占比 | **+0.83** | 0.000 |
| 成纤维 topic 6(CFD/APOD/CXCL14,静息乳头层) | **−0.77** | 0.000 |
| 成纤维中 PTPRC+ 比率 | **+0.73** | 0.000 |
| 样本中位 UMI | +0.66 | 0.002 |
| 成纤维 topic 12(周细胞) | +0.65 | 0.003 |
| 汗腺占比 | −0.58 | 0.011 |
| 角质细胞占比 | −0.48 | 0.040 |
| T 细胞占比 | +0.46 | 0.046 |
| 解离评分 | +0.14 | 0.630(不显著) |
| 成纤维细胞数 | +0.09 | 0.759(不显著) |

整体读法一致:混合权重随**免疫浸润升高、结构性皮肤成分(汗腺/角质/黑素细胞)降低、静息乳头层成纤维减少**而升高。
这是一条**组织炎症/取材状态轴**,不是患者愈合能力。

两项重要保留:

1. **组成型数据本身不独立**。各谱系占比之和为 1,占比之间的相关有一部分是机械的。
   但 `PTPRC+ 比率`(ρ=0.73)与 `样本中位 UMI`(ρ=0.66)是**成纤维内部**的量,不受此约束 —— 前者尤其值得警惕:
   即便绝对 PTPRC+ 比率 <1%,「成纤维免疫信号越重的样本、高-θ 细胞越多」仍是环境 RNA / 免疫浸润的指纹。
2. 细胞级深度已在 7.4b 控制,但**样本级** UMI 仍相关(ρ=0.66),说明样本间的文库差异未被消除。

### 7.4d 加固阴性结果的尝试:反而证明它比之前呈现的更弱

`scripts/22_strengthen_negative_result.py`。"未能拒绝"是阴性结果最弱的形式。
本节做三件事把它变成可证伪的主张,结果有两件不利于原有表述,必须先写。

**B. 功效边界 —— 最重要,且削弱原结论。**

发现集愈合臂的混合权重**样本间标准差为 0.283**,而池化均值仅约 0.27 —— 个体差异与信号同量级。
由此模拟得到:

| 量 | 值 |
|---|---|
| 观测到的愈合组−难愈组差值 | 0.236 |
| **该差值下的检验功效** | **24.9%** |
| 80% 功效所需的最小可检出差值 | **0.519**(约为池化均值的 1.9 倍) |

**这意味着发现集对它自己观测到的效应量只有四分之一的模拟检出功效。** 0.519 是在正态位置平移假设下的设计灵敏度边界，
不是观察效应的置信上限或等效检验;**中等大小的真实愈合关联不能被本队列据此排除**。
因此把"HE-Fibro 丰度不是愈合标志"当作无界否定在原表述下过强,必须改为有界的表述。

**C. 阳性对照 —— 设计确有检出能力。**

用足部皮肤 vs 前臂皮肤(解剖学上确定存在差异)作对照,同一样本级检验、同一 n(9 vs 5):
**15 个主题中 3 个在 p<0.05 分离,最小 p=0.0020**。所以机器能检出真实效应,
阴性结果不是"什么都测不出"。把 B 与 C 合起来读:**该设计能检出大效应,但对愈合这个量级的效应功效不足。**

值得注意的是,分离出来的主题**包含 topic 0 本身** —— 它区分足部与前臂皮肤。
这与"它是创面/炎症读数而非愈合读数"一致。

**A. 阳性替代解释的复现 —— 方向一致,但未被独立确证。**

7.4c 报的 ρ=+0.83 是**B/浆细胞占比**、且仅限足部皮肤。本节同时测两种定义,避免用定义变更掩盖复现失败:

| 定义 | GSE165816(发现) | GSE231643 | GSE241132(独立,作者注释) | 符号一致 |
|---|---|---|---|---|
| 广义免疫细胞合计 | ρ=+0.550, p=0.0009 | +0.357, p=0.385 | **−0.063**, p=0.846 | **否** |
| B/浆细胞(与 7.4c 对应) | ρ=+0.558, p=0.0007 | +0.429, p=0.289 | **+0.147**, p=0.649 | **是** |

**特异版本(B/浆细胞)在三个队列方向一致**(合并 Stouffer Z=+3.29, p=0.001),
而广义免疫版本在独立的急性创面队列里符号翻转。这支持特异主张、否定笼统主张。

但必须同时写明:**两个样本层队列各自都不显著**,合并 p 值由发现集单独驱动；GSE231643 的标题标签不能替代权威患者合同。
这是"方向一致但复现功效不足",不是"已复现"。
另外发现集的估计本身对样本筛选不稳定(随过滤条件在 +0.55 至 +0.83 间变动),该脆弱性应一并披露。

**结论:Direction 2 的可主张范围收窄。**

不可再主张:"HE-Fibro 丰度已被证明不是愈合标志"(功效不足以支持这种无界否定)。

仍然成立且不受功效限制的是以下四条:
(i) 被测量的是混合权重而非程序强度(ρ=0.933,与样本量无关);
(ii) 该细胞状态真实存在并通过解离/双联体/深度三重对照;
(iii) **丰度最高、状态最纯的样本是一例健康非糖尿病足部皮肤(混合权重 0.841,pure_high)** ——
     这是**存在性证据**,不是零假设检验,因此不受功效限制,也是最强的反标志物证据;
(iv) 只能报告在该模拟模型下，大约 1.9 倍均值的效应才有 80% 检出概率；不能写成观察意义上的“已排除”。

第 (iii) 条应当成为该方向的主论据:一个健康对照拥有全队列最纯的"愈合相关"状态,
直接与"该状态标记 DFU 愈合"相矛盾,而且这个矛盾不需要统计功效来支撑。

## 8. 方法轨道:不变性与时序

产品是**带伪迹门禁的单纯形主题 + 混合权重读数 + 冻结迁移 + 时序流匹配**。
DFU 标签与小鼠时点是试验台,不是要证明的临床主张。以下两节是方法结果。

### 8.1 混合权重读数对环境免疫 RNA 是不变的

`scripts/16_ambient_invariance.py`。7.4c 发现权重与 B/浆细胞占比 ρ=+0.83、成纤维 PTPRC+ 比率 ρ=+0.73。
两种读法:**INVARIANT**(状态内生,只是与免疫浸润共现)或 **CONTAMINATED**(权重部分是环境免疫转录本的读数)。

| 测试 | 做法 | 结果 |
|---|---|---|
| **A 细胞纯化** | 剔除 14 个免疫基因上**计数非零**的全部细胞,再加髓系评分 ≤ q25 | 19,410 → 11,262 成纤维;ρ(全部, 纯化)=**+0.989**;双峰 dBIC 由 +41.0 升到 **+56.7** |
| **B 样本残差化** | 权重对 B 细胞/T 细胞/髓系占比 + 免疫阳性率回归 | R²=0.495,残差双峰消失(dBIC −3.9) |
| **B 安慰剂** | 换成周细胞/内皮/黑素/汗腺占比 | R²=0.355,残差双峰**消失得更彻底**(dBIC −8.2) |

**结论(污染):INVARIANT。** 把所有带一丝免疫转录本的细胞全部剔除后,样本混合权重几乎不动(ρ=0.989),
双峰反而更清晰。环境 RNA 不驱动这个读数。

**结论(可分离性):UNDETERMINED。** 安慰剂协变量抹平残差双峰的效果比免疫协变量更强,
说明 n=24 配 4 个预测变量时,**任意**四个协变量都能通过过拟合抹平双峰,Test B 不携带关于免疫的信息。

⚠️ 我最初的预设判定规则把这两个问题合成了一个单词结论(要求 A 与 B 同时通过才算 INVARIANT),
首次运行因此报出 "CONTAMINATED"。那是规则设计错误 —— A 问的是「环境转录本是否抬高读数」,
B 问的是「读数能否与组织免疫组成统计分离」。已拆成两个独立判定,并补上安慰剂对照。

### 8.2 时序流匹配:留出时点失败,失败原因可定位

本节是小鼠探索性运行的历史记录。每个模型×时点只有一个样本，且跨物种面板覆盖、全体标准化和路径假设仍需单独复核；下文的“原因可定位”不能升级为跨物种普遍机制。

`scripts/17_mouse_temporal_flow.py`。GSE326622 是唯一有真实时间轴的队列
(NDB/PDB/GDB × POD0/2/7/30)。每格 n=1 不能做统计推断,但可以做**计算轨迹实验**。
这也是 `load_10x_mtx_dir` 与 flow matching 引擎第一次进入分析脚本。

**Q1 跨物种迁移(冻结人类模型 → 小鼠细胞)**

- 7,002 基因人类靶线按首字母大写映射到小鼠,覆盖 **4,182 / 7,002 = 59.7%**
- 小鼠成纤维 24,459 个,潜空间困惑度 **6.32 / K=15**(人类发现集为 3.69)

迁移**可用但明显退化**:小鼠细胞在主题单纯形上比人类细胞弥散得多,与六成覆盖率一致。

**Q2 留出 POD7**(训练 POD0→POD2、POD2→POD30)

| 能量距离 | 值 |
|---|---|
| 预测 vs 真实 POD7 | **1.2395** |
| 原地不动基线 | **1.0575** |
| POD7 自身对半分(噪声下限) | 0.0102 |
| 相对基线改善 | **−17.2%(更差)** |

**流场输给了「什么都不做」。**

**Q3 测试是否公平** — 是。d(POD2,POD30)=3.610 ≥ max(d(POD2,POD7)=1.057, d(POD7,POD30)=3.135),
POD7 确实落在训练端点之间,不是路径外的偏移。所以失败不能归咎于设计。

**失败原因可定位**:POD2→POD7 只有 1.057,而 POD7→POD30 是 3.135 —— 轨迹严重后置。
但 CFM 的条件路径是**线性插值**,隐含段内匀速;把 POD2→POD30 作为一段跨 t=1/3→1.0 训练后,
积分到 t=2/3 会把细胞推到两端点中间,远远越过 POD7。

**方法结论**:线性插值 CFM 在**段内速度高度不均匀**时,仅凭端点监督无法定位中间状态。
这是 CFM 条件路径设定的固有限制,不是数据不足。可能的修法是按观测时点加密分段、
或改用非线性条件路径(如 schedule 可学的插值),但那是新方法工作,不是再找一个队列。

另需记录:POD30 只有 550 个成纤维,而 POD7 有 12,914,段间样本量极不平衡。

### 8.3–8.6 GSE241132 人类时序与供体条件化：历史记录，发布暂停

`scripts/18_human_temporal_flow.py`、`19_time_parameterisation_fix.py`、

其中 31,230 行跨样本、5,453 行跨供体，成纤维标签中 12,251/12,259 行错配。

### 8.10 第一版外部免疫轴不可用，及其修复（2026-09-18 当日后段）

`scripts/27` 首版报告的免疫与 B/浆细胞比例**不能作为组成估计**，`outputs/repaired_20260918/external_dfu_projection/report.json` 中的 ρ=−0.048 / +0.881 / −0.429 / −0.070 因此作废。两条原因都已量化：

- **gate 饱和。** 两个标志物列表都含 `CD74`（MHC II 恒定链，炎症皮肤中大部分细胞可检出），B/浆细胞列表还含 `CD37`、`CD38`、`SDC1`。读数定义是"检出任意一个标志物的细胞比例"，于是饱和：旧 B/浆细胞比例落在 0.44–0.90，对皮肤组织不是可信的 B/浆细胞丰度。
- **区室不互斥。** 成纤维门与免疫门会把同一细胞算两次，两者之和最大 **1.41**（GSE223964）与 **1.14**（GSE245703）。一个样本同时出现 84% 成纤维样细胞和 92% 免疫细胞。

|---|---:|---:|---:|---:|---|
| GSE223964 | −0.024 | −0.119 | −0.071 | −0.429 | 0.470–0.879 → **0.0019–0.267** |
| GSE245703 | **+0.846** | +0.622 | +0.077 | −0.427 | 0.440–0.901 → **0.0042–0.527** |

修复后的三条结论：广义浸润关联只在两个外部队列之一出现，符号仍不一致；**免疫区室内部**的 B/浆细胞份额与 topic-0 无关，所以 B/浆细胞这一具体替代解释在外部队列不被支持；深度对照在两个队列均为负，与 GSE245703 的正向关联反号，说明那条关联不是测序深度伪迹。
